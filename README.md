## Dataset & Reproducibility

HMEWS is designed using publicly available and credentialed-access
clinical and molecular datasets.

The primary data sources include:

- [MIMIC-IV Clinical Database Demo](https://www.physionet.org/content/mimic-iv-demo/2.2/)
- [MIMIC-IV Clinical Database](https://www.physionet.org/content/mimiciv/3.1/)
- [NCBI Gene Expression Omnibus (GEO)](https://www.ncbi.nlm.nih.gov/geo/)
- [UK Biobank](https://www.ukbiobank.ac.uk/use-our-data/apply-for-access/)

Detailed dataset information, versions, access requirements and usage
restrictions are documented in [`data/sources.md`](./data/sources.md).

> **Important:** Raw restricted datasets are not stored in this
> repository. Users must obtain them directly from the respective
> official sources and comply with their terms of use.
